# CONVOCA · Kit de identidad visual v1.0

**Eslogan:** Conecta oportunidades. Impulsa trayectorias.

**Familia de marca:** CONECTA / RedUniv / Ministerio de Educación Superior de Cuba.

**Portal de referencia:** https://convocatorias.reduniv.edu.cu/

## ¿Qué incluye?

- **01_Logotipos:** vectores SVG trazados independientes de fuente, SVG editables, PNG transparentes, isotipos y favicon.
- **02_Colores:** paleta idéntica a CONECTA v1.0 y tokens listos para CSS/JSON.
- **03_Tipografia:** Inter e IBM Plex Mono, reglas y referencias oficiales (sin archivos de fuentes).
- **04_Textos:** textos para la portada, microcopys de interfaz, SEO y comunicación.
- **05_Recursos_Digitales:** banners, imagen OG, avatares y prototipo HTML local.
- **06_Manual:** manual de identidad de 8 páginas en PDF, con fuente HTML editable.
- **07_Desarrollo:** guía de integración, ejemplos CSS, metadatos y manifest.

## Uso rápido

1. Abrir `06_Manual/manual-de-marca.pdf`.
2. Elegir logotipo SVG o PNG según el fondo.
3. Importar `02_Colores/tokens.css`.
4. Usar Inter como fuente principal e IBM Plex Mono solo para datos técnicos.
5. Adaptar `04_Textos/textos-web.json` al frontend existente.

**Nota de coherencia cromática:** los valores normativos son los de este paquete y coinciden con el kit CONECTA v1.0: azul #102B46, azul noche #0C1D30, menta #49DCCB, turquesa #13B9AA y azul acción #2776C9. Los diseños exploratorios previos podían mostrar tonalidades aproximadas; para producción utilizar estos códigos.

**Alcance:** propuesta lista para evaluación e integración por el equipo; no ha sido desplegada, no cambia el sitio real y no constituye registro o aprobación formal de marca.
