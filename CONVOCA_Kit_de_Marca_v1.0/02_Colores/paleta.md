# Paleta de marca CONVOCA v1.0

**Paleta idéntica a CONECTA v1.0**, extraída de su kit de marca, para mantener una misma identidad visual entre proyectos.

| Nombre | HEX | Aplicación |
|---|---|---|
| Azul CONECTA | `#102B46` | Base, titulares, identidad institucional |
| Azul Noche | `#0C1D30` | Fondos oscuros, encabezados |
| Menta | `#49DCCB` | Acento y llamada a la acción |
| Turquesa | `#13B9AA` | Énfasis secundario |
| Azul Acción | `#2776C9` | Enlaces e interacciones |
| Pizarra | `#4B6278` | Textos secundarios |
| Nube | `#F5F9FC` | Superficies claras |
| Blanco | `#FFFFFF` | Fondo principal |
| Niebla | `#D8E5ED` | Bordes y divisores |

## Proporción orientativa
- Blanco/superficies claras: 50 %.
- Azul CONECTA: 30 %.
- Superficies auxiliares: 15 %.
- Menta: 5 %.

## Accesibilidad
Para texto normal, usar azul oscuro sobre superficies claras; para blanco sobre fondos, priorizar Azul CONECTA y Azul Noche. La menta sobre blanco se reserva para acentos no textuales o texto grande; comprobar contraste según WCAG antes de publicar.
